
# 프로젝트 요구사항

## 질문 (시트 ②)

알고리즘이 익숙한 관심사만 반복해서 보여주는 사회에서, 웹은 내가 평소 관심 두지 않았던 다른 사람들의 관심사와 세계를 보여줌으로써 익숙한 관심의 경계를 넓힐 수 있을까?

## 한 문장 (시트 ⑤)

관심사를 입력하면 위키백과의 연결된 문서들을 따라 낯선 개념으로 이어지는 경로를 지구 위 탐험처럼 시각화해, 익숙한 관심사의 경계를 넓히는 웹 경험.

## 사용 장면 (시트 ⑥)

| 단계 | 사용자가 하는 일 | 화면에서 일어나는 일 |
| --- | --- | --- |
| 1 | 관심사 입력 | 단어에서 파생된 다른 단어들의 위치와 루트가 보임 |
| 2 | 화면에 나오는 루트 따라가기 | 화면에 캐릭터가 새로운 루트를 개척함 |
| 3 | 연결된 새로운 단어의 링크 들어가기 | 링크를 누르면 관련된 위키 페이지가 보여짐 |
| 4 | 다시 웹페이지로 돌아옴 | 들어갔던 링크 건물에 깃발이 꽂힘 |
| 5 | 새로운 관심사 입력 / 그 단어에서 다시 출발 | 단어에서 파생된 다른 단어들의 위치와 루트가 보임 |

## 알파 범위 (시트 ⑧)

- 관심사를 입력하면 한국어·영어 위키백과에서 문서를 찾아 출발점으로 삼는다.
- 문서에 연결된 낯선 단어를 최대 두 단계까지 골라, 단어와 이동 경로를 3D 지구 형태의 화면에 건물과 길로 시각화한다.
- 사용자는 키보드나 화면 클릭으로 캐릭터를 이동하고, 드래그와 휠로 지구를 회전·확대하며 경로를 탐험한다.
- 단어 건물에 도착해 위키백과 문서를 열고, 돌아와 탐험을 이어가거나 해당 단어에서 다시 출발한다.
- 발견한 경로와 현재 탐험 상태를 브라우저에 저장해 다음 방문에도 이어서 볼 수 있다.
