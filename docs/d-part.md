# D. 튜토리얼 · 결말

무전 창 튜토리얼, 진행도와 계급, 탐험 종료 결과 화면, 떠돌이 외계인을 맡는다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `src/ui/mission.js` | D 진입점. 아래 모듈을 묶어서 `app.js`에 한 번만 연결 |
| `src/ui/briefing.js` | 게임 시작 전 임무 브리핑: 계급 제도 설명 → [임무 수락]으로 튜토리얼 시작 |
| `src/ui/radio.js` | 무전 창(타이핑, 클릭하면 전체 표시, 진행 표시, 건너뛰기) + 스포트라이트 |
| `src/ui/tutorial.js` | 착륙 → 1/4~4/4 → 종료. 예외 처리 포함 |
| `src/ui/ending.js` | 위쪽 바 진행도 칩, 패널 아래 [탐험 마치기]/[훈련 다시 받기], 탐사 보고서(결과 화면) |
| `src/ui/wanderer.js` | 떠돌이 외계인 랜덤 이벤트 |
| `src/core/ranks.js` | 계급표 |
| `src/core/progress.js` | 만난 외계인·떠돌이·튜토리얼 완료 저장 (`localStorage` 키 `umm.mission`, 공유 `webglobe3`와 분리) |
| `src/core/events.js` | 트랙끼리 import 없이 주고받는 신호 |
| `src/content/random-word.js` | 떠돌이 외계인 이름(위키 임의 문서) |
| `styles/mission.css` | D 화면 스타일 |
| `tests/mission.mjs` | 계급·게이지 구간·관심 목록·진행도·이벤트 테스트 |
| `src/ui/gauge.js` | 상단 바 '발견한 외계인 수' 게이지(계급 구간 색) |
| `src/ui/collection.js` | 오른쪽 위 '관심·메모' 버튼과 모아 보기 대화상자 |

공용 파일 변경은 `index.html` 스타일 링크 1줄, `src/app.js` 신호 보내기 몇 줄뿐이다.

## 계급 (만난 서로 다른 외계인 수)

| 필요 | 계급 | 한 줄 |
| --- | --- | --- |
| 0 | 견습 우주인 | 헬멧은 썼다. 아직 거꾸로지만. |
| 5 | 베테랑 탐사대원 | (승인된 문장 없음 — 비워 두고 화면에 안 보임) |
| 15 | 가문 연결책 | 이 집 사촌이 저 집 사돈이라는 걸 안다. |
| 30 | 행성의 지배자 | 모든 가족이 너를 안다. 이 행성은 이제 너의 것. |

계급은 4개(사용자 결정 2026-11-25). 필요 수 0/5/15/30은 제안값이라 사용자 확인 대기.

- 외계인을 클릭해 이야기를 처음 들으면 1명(C 트랙의 첫 접촉과 같은 기준). 같은 외계인은 다시 세지 않는다. 떠돌이 외계인과 접촉해도 1명.
- 승급하면 무전 창에 승진 통보와 다음 계급까지 남은 수가 잠깐 뜬다.
- 계급 설명은 게임 전 **임무 브리핑**(처음 접속할 때, [훈련 다시 받기] 때)에 먼저 나온다. 시작 계급과 최종 목표만 공개하고 중간 계급은 `???`.
- 그 밖에 세 군데에 더 있다: 튜토리얼 마지막 무전, 탐사 보고서의 "계급은 이렇게 오른다" 안내, 계급표 각 줄의 한 줄 설명. 아직 못 받은 계급은 `???`와 "N명을 만나면 공개된다"로 보인다.
- 떠돌이 외계인은 튜토리얼을 마치거나 건너뛴 뒤라면 착륙 전에도 화면 가운데 근처에 나타난다.
- 숫자와 이름은 `src/core/ranks.js` 한 곳만 바꾸면 된다.

## 다른 트랙과 연결 (`src/core/events.js`)

D는 다른 트랙 파일을 import하지 않고, `app.js`가 보내는 신호만 듣는다.

| 신호 | 보내는 곳 (`app.js`) | D에서 쓰는 곳 |
| --- | --- | --- |
| `journeyStart` / `journeyEnd` / `journeyMessage` | 여정 시작·끝·실패 문구 | 튜토리얼 1/4, 가족 추적 |
| `arrive` | 외계인·길 도착 | 튜토리얼 2/4, 새 외계인 도착 |
| `contact` | C의 첫 접촉(`onFirstContact`, 문서당 1회) | 만난 외계인 수 → 계급 |

튜토리얼이 밝히는 화면 요소는 `tutorial.js` 맨 위 `HOOKS`에 모여 있다 (입력 창 `#bar`, 외계인 창 `#resultActions`, 이야기 창 `#story`, 가족 후보 `#familyBoxes`). C의 마크업 id가 바뀌면 여기만 고치면 된다.

| 튜토리얼 단계 | 연결된 기능 |
| --- | --- |
| 1/4 입력 | 입력 창 + 출발 → 첫 외계인 |
| 2/4 접근 | 첫 외계인 앞 도착 (바로 앞에 착륙하면 곧바로 완료) |
| 3/4 접촉 | 외계인 클릭 또는 '이야기 듣기' → 이야기 창 (C) |
| 4/4 가족 추적 | 가족 후보 3칸 중 하나 선택 → 길 생성 → 새 외계인에게 이동 (C) |
| 예외 | 가족 후보가 없으면 1/4로 돌아가 다른 이름으로 다시 출발 |

## 확인

```sh
node scripts/check-wiki.mjs
node tests/wiki-explorer.mjs
node tests/wiki-boundaries.mjs
node tests/mission.mjs
```

- 튜토리얼을 다시 보려면 패널 아래 [훈련 다시 받기], 또는 개발자 도구에서 `localStorage.removeItem('umm.mission')` 후 새로고침.
- 발표용: 주소 뒤에 `?demo`를 붙이면 떠돌이 외계인이 8~15초마다 나타난다 (기본은 45~100초).
