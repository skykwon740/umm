# 바깥 — 기록에서 출발하는 웹 탐방

픽셀 지구본 위에 가상 인물 5명의 검색·방문 기록을 영토로 구성한 로컬 프로토타입입니다. 한 건물은 한 개별 페이지입니다. 같은 도메인의 글도 URL이 다르면 별개 건물이며, 같은 페이지를 방문한 인물은 각각 자기 영토에 기록을 가집니다.

## 실행

Node.js 22 이상에서 `npm start` 후 http://127.0.0.1:4173/ 을 엽니다. 설치·빌드가 필요하지 않습니다. 안전 검사와 실시간 추첨은 `server.mjs`가 필요하므로 정적 파일만 배포해서는 동작하지 않습니다.

- 드래그·휠: 회전·확대. 방향키/WASD: 이동. 건물 선택: 해당 페이지로 이동.
- ⌂: 출발점. 인물 이름: 상세 프로필과 전체 가상 기록, 출발 인물 변경.
- ⚄: 내 영토 → 란더노티카 관문 → 검사된 무작위 페이지로 자동 이동.
- 도착 후 새 창이 열리면 10분 타이머 시작. 팝업 차단 시 ‘열기’를 직접 누릅니다.
- 탐방 후 자기 말로 요약·확인 근거·질문을 남깁니다. 일찍 끝내면 실제 경과 시간을 저장합니다.
- ▤: 아카이브 내보내기·가져오기·같은 URL의 요약 비교·AI 평가 요청문 복사.
- ⊘: 해당 도메인을 로컬 신고·제외 목록에 추가. 외부 기관에 신고를 전송하지 않습니다.
- 검색: 세계에 있는 페이지·검색어·맥락 찾기. 직접 URL은 검사 후 추가.

## 인물과 기록

윤서(미디어 학생), 민재(도시환경 연구·필드 레코딩), 수빈(편집 디자인·제본), 지후(과학 교사), 나래(제품 시각화·테라리움)의 생활 제약·목표·습관·상충하는 관심·해석 주의점을 작성했습니다. 2026-10-20~11-02의 가상 활동 246건에는 검색어, 방문 시각, 이전 이벤트, 체류 시간, 세션 목적, 관찰 메모가 있습니다. 실제 사용자 활동이나 측정 데이터가 아닙니다. 인물마다 활동하는 매체 비중이 다릅니다.

`scripts/persona-seeds.mjs`가 원본 시나리오이고 `npm run generate:personas`가 `dist/data/personas.json`을 생성합니다. 이전 실제 기록의 `.local/seed-history.json`은 읽지 않으며, 해당 내용을 제공하던 API도 제거했습니다. `.local/`은 Git에서 제외됩니다.

## 우연한 발견

[Wiby Surprise](https://wiby.me/surprise/) 또는 [Marginalia Explore](https://marginalia-search.com/explore)의 실시간 진입점에서 시작해, 실제 HTML 링크를 1~2회 추첨합니다. 내부 하위 페이지가 있으면 우선 사용합니다. 개인 블로그 글, 오래된 홈페이지의 작은 페이지, 공개 게시물, 영상 링크를 도메인 유명도로 제한하지 않습니다. 열람에는 공개 HTTPS HTML과 검사 통과가 필요합니다.

전체 공개 웹의 완전한 목록이나 균등 분포가 아닙니다. 인덱스·링크·HTTPS 지원에 따른 편향이 있습니다. 초기 지도 예시 페이지와 실시간 추첨을 구분하며 실패하면 고정된 페이지로 대체하지 않습니다. 출발 질문은 기록만 하고 추첨에 영향을 주지 않습니다. 란더노티카의 ‘의도 → 무작위 목적지 → 관찰’ 흐름을 웹으로 응용했으며 공식 서비스/API 연동이나 양자 난수 생성이 아닙니다.

## 안전 검사와 한계

모든 외부 열기와 영상 재생 요청은 로컬 검사 API를 거칩니다. 새 랜덤 목적지는 검사 통과 후에만 추가합니다.

- Cloudflare malware/phishing DoH 도메인 평판 검사. 응답 실패·차단·주소 확인 실패 시 열지 않음.
- 각 HTTP·meta refresh 리디렉션을 재검사. 5회 초과 제외.
- 로컬·사설·예약 IP, IP 직접 주소, 비공개 도메인, 인증정보 포함 URL, 임의 포트 제외.
- 확인된 공개 IP에 TLS 요청을 고정해 DNS 재바인딩 방지. 인증서 검증 유지.
- 실행 파일·압축파일·첨부 다운로드·비 HTML 응답 제외. 응답 512KB·요청 10초 상한.
- 명시적 불법 거래 관련 URL·제목·본문 규칙과 사용자의 도메인 제외 목록 적용.
- 메타데이터 검사 중 원격 스크립트는 실행하지 않음. 검사 API는 로컬 Origin의 POST만 허용.

도메인 평판은 백신 파일 검사나 모든 페이지의 합법성 판정이 아닙니다. 불법 콘텐츠 탐지는 제한된 규칙이므로 누락·오탐이 있으며, 등록되지 않은 위협, 방문 후 변경된 콘텐츠, 자바스크립트 이동, 외부 브라우저에서 클릭한 후속 링크는 보호 범위 밖입니다. ‘검사 통과’는 안전·합법 보증이 아닙니다. 실제 공개 서비스에는 전문 URL 위협·콘텐츠 분류 서비스와 운영 차단 목록의 추가 연결이 필요합니다.

## 요약과 비교

같은 페이지는 canonical URL을 키로 공통 페이지 레지스트리에 한 번만 등록합니다. 각 영토의 건물은 인물별 방문 흔적이며 공통 페이지를 참조합니다. ‘N명의 방문 흔적’에서 각자의 방문 횟수·검색어·맥락을 별도로 보고 해당 영토로 이동할 수 있습니다. 페이지를 먼저 발견한 사람이 다른 사람의 영토나 요약을 차지하지 않습니다. 같은 도메인이라도 다른 글은 합치지 않으며 YouTube shorts/watch의 같은 영상 ID는 합칩니다. 리디렉션·미러·번역 페이지를 추측만으로 합치지 않습니다.

실제 온라인 공유 단계에서는 페이지(canonical URL 고유), 개인 방문(event ID 고유), 보관(user+page 고유), 요약(작성자+탐방+버전)을 별도 저장하는 구조가 필요합니다. 동시 공유는 페이지 upsert로 병합하고 개인 기록은 덮어쓰지 않습니다. 방문·검색 기록은 기본 비공개, 공개를 선택한 요약만 비교 대상으로 삼아야 합니다. 이 로컬 프로토타입은 인증·동시 쓰기·공개 권한 서버가 연결된 상태가 아니며, 현재 공유 흔적은 모두 가상 인물 시나리오입니다.

요약은 현재 브라우저 localStorage에 저장합니다. 먼저 자신의 요약을 작성한 뒤 정확히 같은 canonical URL의 다른 기록과 비교합니다. 무작위 목적지가 우연히 겹치기 어렵기 때문에 다른 탐방자의 아카이브 JSON을 가져올 수 있습니다. Zooniverse 소개 페이지에 한해 가상 인물의 비교용 요약 3개가 있으며 ‘가상 작성 예시’로 표시합니다. 실제 타인의 글이나 AI 평가 결과로 위장하지 않습니다.

자동 AI 평가는 아직 연결되지 않았습니다. 원문 확인 여부·관찰 근거·사실과 추론의 구분을 요청하는 프롬프트를 복사할 수 있고, 아카이브의 evaluation은 null입니다. 다른 사용자의 온라인 공유·동기화도 연결되지 않았습니다. 10분은 새 창을 연 시점부터의 경과 시간이며 실제 페이지 활동을 추적하지 않습니다.

## 모듈 구조

- `dist/app.js`: 앱 상태·모듈 연결.
- `dist/content/persona-world.js`: 개별 페이지 식별·기록 기반 영토.
- `dist/content/expeditions.js`, `safe-open.js`: 타이머·아카이브·검사 후 열기.
- `dist/ui/personas.js`, `expedition.js`: 프로필·여행·작성·비교 UI.
- `server/safe-web.mjs`, `wander.mjs`: URL/DNS/HTML 검사·실시간 링크 추첨.
- `dist/world/`: 구면 투영·픽셀 표면·지형·건물·경로. 콘텐츠와 분리.
- `dist/media/`: 영상 플레이어. `dist/styles/`: 화면별 CSS.
- `scripts/`: 가상 기록 생성·구문 검사. `tests/`: 엔진·입력·보안·아카이브 검사.

이전 영상·도메인 단위 모델은 회귀 테스트용으로 남겼으며 현재 화면은 인물·개별 페이지 모델을 사용합니다. 새 상태는 `outside-persona-world-v1`, 탐방 기록은 `outside-expedition-archive-v1` 키를 사용합니다.

## 검증

`npm run check`와 `npm test`: 모듈/import·HTML ID, 구면 투영·경로·도착 시 선택, 인물별 건물 누락·중첩·연결, 246개 이벤트·참조 관계, 영상 URL, 10분 기한·요약·동일 URL 비교, 사설주소·리디렉션·평판 실패·다운로드·제외 규칙·신고 도메인·링크 추첨을 검사합니다. 실제 네트워크에서도 공개 페이지 검사와 개인 사이트 하위 페이지의 실시간 추첨을 확인했습니다.
