# umm

웹사이트를 건물로, 웹을 하나의 지구로 보는 탐험 프로토타입.

관심사를 하나 입력하면 위키피디아 문서를 따라 단어를 이어가며 루트를 만든다. 지나간 길과 들른 주소만 지구 위에 밝혀지고, 나머지는 어둡게 남는다. 아직 모르는 곳이 얼마나 넓은지 느끼게 하는 것이 목표다.

## 실행

`index.html`에서 시작하며, 기능별 코드는 `src/`, 화면별 스타일은 `styles/`에 있다. Node.js 22 이상에서 패키지 설치나 빌드 없이 실행한다.

```bash
node scripts/serve-wiki.mjs
```

브라우저에서 `http://127.0.0.1:8765`를 연다. ES 모듈을 사용하므로 HTTP 서버로 열어야 한다. 파일별 작업 경계와 상태 변경 규칙, 검사 방법은 [개발 가이드](docs/wiki-development.md)를 참고한다.

## 흐름

1. 처음 화면은 **행성계**: 열린 행성을 누르면 그 행성을 탐험한다. 앞 행성에서 최고 계급(행성의 지배자)이 되면 다음 행성이 열린다
2. 오른쪽 패널에 관심사를 입력하고 **출발**
3. 위키피디아에서 그 단어를 검색해 첫 외계인(문서)을 놓고, 캐릭터는 그 앞에서 시작한다. 위키에 없는 단어면 안내만 뜨고 캐릭터와 루트는 그대로다
4. 외계인 칸에 도착하면 정보창이 저절로 열린다(닫은 뒤에는 서 있는 외계인을 클릭): 문서 요약, **위키백과 원문 / 이미지**, 하트·메모, 가족 3개(↻로 다시 뽑기)
5. 정보창을 처음 연 외계인은 깨어나 루트 색으로 바뀌고, 만난 외계인 수가 1 오른다(같은 단어는 한 번만)
6. 가족 하나를 고르면 새 외계인이 놓이고, 패널에 단어와 한 줄 설명이 이어진다. **자동 이동**이 켜져 있으면 캐릭터가 바로 걸어가고, 꺼져 있으면 카메라가 새 외계인에 고정되어 클릭해서 간다
7. 이미 만난 외계인을 다시 열면 가족을 새로 뽑는다
8. 새 관심사를 입력해 다시 출발(새 루트는 다른 색의 떨어진 섬)
9. **탐험 마치기** → 탐사 보고서 → **행성계로** 처음 화면으로 돌아간다

가족은 문서 속 링크 단어에서 무작위로 고른다. 날짜·연도·숫자·목록 문서와 동음이의 문서, 이미 지구에 있는 외계인은 뺀다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 검색창 입력 후 출발 | 관심사 검색 (1~100자, 검색창 Enter도 가능) |
| 길·외계인 클릭 | 해당 위치까지 걷기. 다시 클릭하면 목적지 변경, 현재 위치를 클릭하면 멈춤 |
| 서 있는 외계인 클릭 | 정보창 다시 열기 |
| Esc | 정보창 닫기 |
| 드래그 | 지구 회전 |
| 지구 위 휠 | 확대 / 축소 |
| 캐릭터로 돌아가기 | 수동 회전으로 해제한 카메라 추적 재개 |
| 관심 표시 / 메모 | 도착한 단어에 하트와 최대 500자 메모 저장 |

먼 목적지일수록 빠르게 이동하고 가까워지면 감속한다. 방향키·WASD 이동과 전역 Enter 동작은 사용하지 않는다. 검색·메모 입력, 버튼·링크의 기본 키보드 조작은 가능하다. 메모는 입력하면 자동으로 저장된다.

## 화면

- **위쪽 바**: 발견한 외계인 수와 계급 구간 게이지, 오른쪽 위 관심·메모 모아 보기
- **루트 색 길**: 캐릭터가 실제로 걸어간 칸 (루트마다 한 색)
- **외계인**: 아직 정보창을 열지 않은 외계인은 기본 모습, 연 외계인은 깨어난 모습으로 루트 색이 된다
- **우주인**: 계급이 오를 때마다 작은 외계인이 한 마리씩(최대 3) 따라다니고 헬멧 유리가 계급 색이 된다
- **무전 창**: 첫 탐험의 튜토리얼, 승진 통보, 떠돌이 외계인 포착 알림

## 참고

- 입력에 한글이 있으면 한국어 위키피디아, 아니면 영어 위키피디아를 쓴다.
- 탐험 기록은 브라우저 `localStorage`에 저장된다. 관심 표시와 메모는 별도 키에 저장되며 언어와 문서 제목으로 구분된다. 행성마다 따로 저장한다(1번 행성은 예전 키 그대로). 지우면 지구가 처음 상태로 돌아간다.
- 아직 없는 것: 위키피디아 다음 단계의 실제 웹사이트 연결, Google Safe Browsing 검사, 결과 페이지(다른 담당. 지금은 탐사 보고서가 그 자리에 있다).
