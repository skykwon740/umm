# umm

웹사이트를 건물로, 웹을 하나의 지구로 보는 탐험 프로토타입.

관심사를 하나 입력하면 위키피디아 문서를 따라 단어를 이어가며 루트를 만든다. 지나간 길과 들른 주소만 지구 위에 밝혀지고, 나머지는 어둡게 남는다. 아직 모르는 곳이 얼마나 넓은지 느끼게 하는 것이 목표다.

## 실행

`index.html`에서 시작하며, 기능별 코드는 `src/`, 화면별 스타일은 `styles/`에 있다. Node.js 22 이상에서 패키지 설치나 빌드 없이 실행한다.

```bash
node scripts/serve-wiki.mjs
```

브라우저에서 `http://127.0.0.1:8765`를 연다. ES 모듈을 사용하므로 HTTP 서버로 열어야 한다. 파일별 작업 경계와 상태 변경 규칙, 검사 방법은 [개발 가이드](docs/wiki-development.md)를 참고한다.

## 흐름

1. 오른쪽 패널에 관심사를 입력하고 **출발**
2. 위키피디아에서 그 단어를 검색해 첫 외계인(문서)을 놓고, 캐릭터는 그 앞에서 시작한다
3. 외계인 앞에서 **이야기 듣기**(또는 서 있는 외계인 클릭)를 누르면 이야기 창이 열린다: 문서 요약, **위키백과 원문 / 구글 이미지**, **창 안에서 보기**, 가족 후보 3개
4. 처음 이야기를 들은 외계인에는 깃발이 꽂힌다
5. 가족 후보 하나를 고르면 새 외계인까지 루트가 깜빡이며 그려지고, 패널에 단어와 한 줄 설명이 이어진다
6. 캐릭터를 움직여 새 외계인에게 간다. 이미 만난 외계인을 다시 열면 가족 후보를 새로 뽑는다
7. 새 관심사를 입력하거나 **이 주소에서 다시 출발**

가족 후보는 문서 속 링크 단어에서 무작위로 고른다. 날짜·연도·숫자·목록 문서와 동음이의 문서, 이미 지구에 있는 외계인은 뺀다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 검색창 입력 후 출발 | 관심사 검색 (1~100자, 검색창 Enter도 가능) |
| 길·외계인 클릭 | 해당 위치까지 걷기. 다시 클릭하면 목적지 변경, 현재 위치를 클릭하면 멈춤 |
| 서 있는 외계인 클릭 | 이야기 듣기 |
| Esc | 이야기 창 닫기 |
| 드래그 | 지구 회전 |
| 지구 위 휠 | 확대 / 축소 |
| 캐릭터로 돌아가기 | 수동 회전으로 해제한 카메라 추적 재개 |
| 관심 표시 / 메모 | 도착한 단어에 하트와 최대 500자 메모 저장 |

먼 목적지일수록 빠르게 이동하고 가까워지면 감속한다. 방향키·WASD 이동과 전역 Enter 동작은 사용하지 않는다. 검색·메모 입력, 버튼·링크의 기본 키보드 조작은 가능하다. 메모는 다른 장소로 이동하기 전에 **메모 저장**을 누른다.

## 화면

- **위쪽 바**: 지구 전체 중 발견한 면적 %
- **파란 길**: 걸을 수 있는 길
- **흰·회색 깜빡임**: 아직 걷지 않은 이번 루트
- **주황 건물 / 파란 타일 + 깃발**: 루트 위 외계인 / 이야기를 들은 외계인 (외계인 그림이 나오기 전까지 건물로 표시)

## 참고

- 입력에 한글이 있으면 한국어 위키피디아, 아니면 영어 위키피디아를 쓴다.
- 탐험 기록은 브라우저 `localStorage`에 저장된다. 관심 표시와 메모는 별도 키에 저장되며 언어와 문서 제목으로 구분된다. 지우면 지구가 처음 상태로 돌아간다.
- 아직 없는 것: 위키피디아 다음 단계의 실제 웹사이트 연결, Google Safe Browsing 검사, 여행 리포트.
