# umm

웹사이트를 건물로, 웹을 하나의 지구로 보는 탐험 프로토타입.

관심사를 하나 입력하면 위키피디아 문서를 따라 단어를 이어가며 루트를 만든다. 지나간 길과 들른 주소만 지구 위에 밝혀지고, 나머지는 어둡게 남는다. 아직 모르는 곳이 얼마나 넓은지 느끼게 하는 것이 목표다.

## 실행

`index.html`에서 시작하며, 기능별 코드는 `src/`, 화면별 스타일은 `styles/`에 있다. Node.js 22 이상에서 패키지 설치나 빌드 없이 실행한다.

```bash
node scripts/serve-wiki.mjs
```

브라우저에서 `http://127.0.0.1:8765`를 연다. ES 모듈을 사용하므로 HTTP 서버로 열어야 한다. 파일별 작업 경계와 상태 변경 규칙, 검사 방법은 [개발 가이드](docs/wiki-development.md)를 참고한다.

## 흐름

1. 오른쪽 패널에 관심사를 입력하고 **출발**
2. 위키피디아에서 그 단어를 검색하고, 문서 속 링크 중 하나를 골라 다시 검색한다 (2번 이어감)
3. 지구 위에 루트가 깜빡이며 그려지고, 패널에 지나는 단어와 한 줄 설명이 뜬다
4. 캐릭터를 움직여 루트 위의 건물로 간다
5. 건물 위에서 **위키백과 / 구글 이미지**를 선택하면 도착한 단어의 결과가 새 탭으로 열리고, 건물에 깃발이 꽂힌다
6. 새 관심사를 입력하거나 **이 주소에서 다시 출발**

단어는 무작위가 아니라, 원래 문서로 되돌아 링크하지 않는 문서를 우선 골라 "연결되어 있지만 예상 밖인" 곳으로 가도록 했다. (예: 게임 디자인 → 규칙 → 법률)

## 조작

| 입력 | 동작 |
| --- | --- |
| Enter | 출발 / 위키백과 열기 (링크에 초점이 있으면 해당 링크 열기) |
| ↑ ↓ ← → | 이동 |
| 타일 클릭 | 그 타일까지 걸어가기 (루트가 그려진 순서를 따름) |
| 드래그 | 지구 회전 |
| 휠 | 확대 / 축소 |

## 화면

- **위쪽 바**: 지구 전체 중 발견한 면적 %
- **파란 길**: 걸을 수 있는 길
- **흰·회색 깜빡임**: 아직 걷지 않은 이번 루트
- **주황 건물 / 파란 타일 + 깃발**: 루트 위 주소 / 들어가 본 주소

## 참고

- 입력에 한글이 있으면 한국어 위키피디아, 아니면 영어 위키피디아를 쓴다.
- 탐험 기록은 브라우저 `localStorage`에 저장된다. 지우면 지구가 처음 상태로 돌아간다.
- 아직 없는 것: 위키피디아 다음 단계의 실제 웹사이트 연결, Google Safe Browsing 검사, 여행 리포트.
